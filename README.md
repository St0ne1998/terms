# Khreor Fashion Website Terms and Conditions of Use - Legal Page

A fully responsive, mobile-friendly legal terms and conditions page featuring a scroll-triggered interactive popup for **Khreor Fashion**.

---

## 🚀 Features

* **Clean & Professional Typography:** Optimized for reading lengthy multi-vendor marketplace legal terms, South African consumer compliance sections (CPA & ECTA), and POPIA data privacy policies with high legibility across mobile and desktop viewports.
* **Scroll-Triggered End-of-Page Detection:** The popup modal locks and displays automatically only *after* the user scrolls completely to the bottom of the terms, verifying that they have finished reading.
* **Single Action Redirection:**
  * **Back to Store Button:** Directs users seamlessly back to the main storefront at `https://www.khreorfashion.store`.
* **Mobile-First Responsive Layout:** Includes adaptive padding, responsive media queries, touch-friendly CTA sizing, and a centered card overlay.
